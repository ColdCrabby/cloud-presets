# schemas/

Vendored copy of the JSON Schemas published by
[`ColdCrabby/slicer`](https://github.com/ColdCrabby/slicer)
(`slicer-engine-{printer,filament,process}-profile-v1.json`).

This is a **pinned, reviewable copy — not a submodule**. A schema bump lands as
an explicit PR so it is a visible, deliberate act. Ingest and the validator CLI
both validate against these files. The actual schema files are vendored in a
later foundation-wave issue. See
[ARCHITECTURE.md](../ARCHITECTURE.md#monorepo-layout).
